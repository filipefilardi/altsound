# AltSound

## Short description

Stream and download your Jellyfin music library with a modern mobile player.

## Full description

AltSound is a clean, modern music player for your Jellyfin library. Connect to your Jellyfin server and stream your albums, artists, playlists, and favorite songs from a mobile interface built for listening.

Browse recently added, most played, and recently played music, search across songs, albums, and artists, manage your queue, and pick up where you left off. AltSound also supports offline downloads on iOS and Android, so you can keep albums and playlists available when your connection drops.

Features include:

- Streaming from your Jellyfin music library
- Album, artist, playlist, and liked songs browsing
- Search for songs, albums, and artists
- Queue management and full-screen now playing controls
- Offline downloads for iOS and Android
- Local playback plus playback handoff to other Jellyfin sessions

AltSound requires access to a Jellyfin server with a music library.

## Run

### Requirements

- Flutter SDK installed
- A running Jellyfin server
- Device or emulator (Android/iOS)

### How to run

```bash
flutter pub get
flutter run
```
